
# NEON RUSH: SWITCH — Agent Instructions

## Project
- HTML5 arcade game for Yandex Games.
- Stack: Phaser, TypeScript, Vite.
- Mobile-first, portrait gameplay.
- Russian primary UI, English secondary UI.

## Development rules
- Work only inside this repository.
- Prefer simple, maintainable, modular code.
- Preserve existing working gameplay.
- Implement one milestone at a time.
- Never introduce paid services or unnecessary dependencies.
- Do not commit secrets or generated build output.
- Do not change unrelated system files.
- Explain significant architectural decisions.

## Quality
- Run type checking, tests, and build validation after significant changes.
- Report which checks actually passed or failed.
- Do not claim browser testing was performed unless it was.
- Keep GitHub Pages preview and Yandex production builds separate.
- Preserve compatibility with mobile browsers.

## Git
- Do not overwrite Git history or force-push.
- Do not commit, push, merge, or create pull requests without explicit instruction.
- Avoid destructive Git commands.

## Communication
- Respond to the developer in Russian.
- Keep documentation and code identifiers in English unless otherwise specified.
