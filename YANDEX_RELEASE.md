# Подготовка релиза для Yandex Games

## Статус этапа 1

Сейчас готовы игровое ядро, отдельная статическая цель `yandex`, скрипты проверки и ZIP с `index.html` в корне. SDK, облачное сохранение, автоматический язык платформы и реклама не реализованы. Не отправляйте этот прототип на модерацию как законченный платформенный релиз. GitHub Pages проверяет standalone и не подтверждает работу SDK.

## 1. Издатель и доступ

- [ ] Совершеннолетний издатель вручную проверил актуальные условия, создал нужную учётную запись и получил доступ к консоли.
- [ ] Договоры и реквизиты оформляет сам издатель; агент не регистрирует аккаунты, не принимает соглашения и не выполняет платежи.
- [ ] Для описанного 17-летнего разработчика публикация с договором и выплатами требует подходящего взрослого издателя до достижения установленного возраста. По [официальной информации о монетизации](https://yandex.ru/dev/games/doc/ru/services/about-monetization), лицензионное соглашение и выплаты доступны с 18 лет; при оформлении на родителя или другое лицо права и обязанности относятся к нему.

Для разработки и тестирования Pages ничего из этого не требуется.

## 2. SDK и жизненный цикл — этап 4

- [ ] В Yandex-сборке подключён официальный `/sdk.js` по [актуальной инструкции](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about); в standalone нет зависимости от SDK.
- [ ] SDK инициализируется безопасно; отказ загрузки не ломает игровой интерфейс.
- [ ] `LoadingAPI.ready()` вызывается один раз после готовности canvas, меню и обработчиков управления.
- [ ] `GameplayAPI.start()` вызывается при активном забеге и возобновлении; `stop()` — при меню, паузе, проигрыше и прерывании.
- [ ] Обработаны настоящие `game_api_pause` / `game_api_resume`, `visibilitychange` и реклама; события SDK не подделываются.
- [ ] В черновике сверены вызовы с [требованиями к методам SDK](https://yandex.ru/dev/games/doc/ru/requirements/1/19) и debug-панелью платформы.

## 3. Реклама — этап 4

- [ ] Используется только официальный SDK; standalone не запрашивает настоящую рекламу.
- [ ] На время рекламы остановлены модель и звук; восстановление учитывает состояние до показа и видимость страницы.
- [ ] Fullscreen показывается только вне активного забега и соблюдает дополнительный интервал между показами.
- [ ] Revive доступен один раз за забег и возвращает игрока в безопасную ситуацию с временной защитой.
- [ ] Удвоение валюты доступно один раз за результат.
- [ ] Награда выдаётся только по `onRewarded`, повторные callbacks не дублируют её; `onClose` сам по себе не награждает. Проверены отказ, пропуск и прерывание, согласно [документации рекламы](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv).
- [ ] DEBUG mock отсутствует в Yandex-сборке; отсутствие рекламного провайдера не выдаёт поддельных наград.

Платежи и внутриигровые покупки не входят в первоначальный релиз.

## 4. Язык и сохранение — этапы 3–4

- [ ] В платформенной версии язык берётся из `ysdk.environment.i18n.lang`; поддержаны русский и английский, для остальных документирован русский fallback.
- [ ] В standalone используется язык браузера и доступен ручной выбор.
- [ ] `SaveManager` сохраняет версию, рекорд, валюту, косметику, задания, ежедневные награды, статистику и настройки.
- [ ] При доступности используются Player Data API и ограниченная частота облачных записей; без авторизации и сети остаётся локальный режим.
- [ ] Проверены повреждённые данные, запрет localStorage, миграции, конфликт свежести и повторная выдача наград.

## 5. Сборка и архив

```bash
npm ci
npm run typecheck
npm run lint
npm run test
npm run build
npm run validate:build
npm run package:yandex
npm run validate:zip
```

- [ ] Выбран свежий `artifacts/neon-rush-yandex.zip`, а не standalone и не внешний контейнер GitHub artifact.
- [ ] В корне архива один `index.html`, ресурсы относительные и существуют; не нужен отдельный сервер приложения.
- [ ] Имена файлов содержат ASCII без пробелов, нет секретов, исходников и карт исходного кода.
- [ ] Содержимое до сжатия меньше 100 МБ. Эти требования приведены в [инструкции загрузки игры](https://yandex.ru/dev/games/doc/ru/console/add-new-game).
- [ ] В этапе 4 обновлён валидатор метаданных: он подтверждает реальное подключение SDK и отсутствие DEBUG-рекламы. Сейчас он намеренно принимает только основу этапа 1 с `sdkIntegrated: false`.

## 6. Материалы и черновик

- [ ] Название в игре, описании и материалах — `NEON RUSH: SWITCH`.
- [ ] Подготовлены оригинальная иконка, обложка и настоящие скриншоты; размеры сверены с текущими полями консоли.
- [ ] Русский и английский тексты описывают только реально реализованные функции.
- [ ] Взрослый издатель вручную создал черновик в консоли, загрузил ZIP и проверил игру в режиме черновика.
- [ ] Проверены Android, другие мобильные браузеры и desktop: управление, ориентация, безопасные области, пауза, потеря фокуса, перезапуск и длительный забег.
- [ ] Проверены консоль браузера и debug-панель Yandex: загрузка, Game Ready, Gameplay, реклама, язык и сохранение.
- [ ] Устранены ошибки и сверены актуальные требования модерации. Только после этого издатель вручную отправляет игру на проверку и решает вопрос публикации.

## Известные ограничения первого этапа

Сохранён только локальный рекорд. Нет полного SDK lifecycle, рекламных наград, Player Data, экономики, интерактивного туториала или автоматического языка. Состояние GitHub Actions и настоящий телефон проверяются отдельно; успешная локальная сборка не является доказательством прохождения модерации.
