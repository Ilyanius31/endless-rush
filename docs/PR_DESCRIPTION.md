# Этап 1: играбельное ядро NEON RUSH: SWITCH и браузерный preview

Разработчик может запустить портретную аркаду локально или, после настройки Pages и ручного merge, открыть standalone в браузере телефона. В репозитории есть Phaser/TypeScript/Vite, неоновая сфера на двух полосах, меню RU/EN, управление касанием, мышью и клавиатурой, пауза, столкновения, дистанционный счёт, локальный рекорд и мгновенный перезапуск.

Модель отделена от рендера. Переход имеет явные состояния и не разворачивается повторными касаниями; столкновения проверяют круг и весь отрезок движения. Генератор подтверждает достижимость через безопасные временные окна с учётом ускорения и длительности перехода. Проверки включают 1 000 воспроизводимых последовательностей на четырёх уровнях сложности.

Standalone и Yandex собираются в разные каталоги. CI на Node.js 24 LTS проверяет типы, lint, тесты, ресурсы и ZIP, затем запускает Chromium и сохраняет артефакты. Pages workflow публикует проверенный артефакт успешного CI из `main`. Yandex ZIP является основой упаковки; SDK, реклама и облачные данные относятся к последующим этапам.

## Проверка перед ревью

```bash
npm ci
npm run typecheck
npm run lint
npm run test
npm run build
npm run validate:build
npm run package:yandex
npm run validate:zip
npm run test:browser
PAGES_BASE_PATH=/endless-rush/ npm run build:preview
PAGES_BASE_PATH=/endless-rush/ npm run test:browser -- --config playwright.preview.config.ts
```

Локально также проверен синтаксис workflows с `actionlint`. Фактические результаты выполнения следует сверить с отчётом разработчика и первым запуском CI. Настоящий Android, SDK и модерация пока не проверены.

Изменения подготовлены в рабочем дереве. Этот файл — текст для будущего PR; коммит, push, создание PR и merge выполняются отдельно по разрешению разработчика.
